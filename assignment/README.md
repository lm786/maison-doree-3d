# Maison Dorée — 3D Web App
H7006 Web 3D Applications · University of Sussex · 2025/26

A 3D interactive café menu built with Three.js. 
Select between three food items, rotate them in 3D, 
toggle wireframe, change colours, and control lighting.

## Live URL
https://users.sussex.ac.uk/~lm786/assignment/index.html

## How to run locally
Open in VS Code → right-click index.html → Open with Live Server → view in Chrome

## Files
- index.html — main app
- submission.html — submission details
- models/ — GLB 3D model files
- audio/ — café ambient audio
